# "My Rights" Project

A project to help users understand their rights when encountering federal agents and provide tips and resources. This is an i18n project that includes multiple languages.

[![Netlify Status](https://api.netlify.com/api/v1/badges/381e01e9-5185-45c2-bda0-2408edfc9108/deploy-status)](https://app.netlify.com/projects/myrightshelp/deploys)

## Tech

- [Bun](https://bun.sh)
- [Astro](https://astro.build)
- [Shadcn UI](https://ui.shadcn.com)
- [Tailwind CSS](https://tailwindcss.com)
- [Netlify](https://netlify.com)

## Getting Started

First, install dependencies:

```bash
bun i
```

Then, run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:4321) with your browser to see the result.
