# My Rights

[![Netlify Status](https://api.netlify.com/api/v1/badges/381e01e9-5185-45c2-bda0-2408edfc9108/deploy-status)](https://app.netlify.com/projects/myrightshelp/deploys)

A bilingual website that helps people understand their rights when encountering federal agents in
the United States. It pairs a plain-language guide (silence and identification, detainment and
arrest, searches, filming) with national resources and a search for local organizations by city.

The guide is available in English at `/` and Spanish at `/es`. Local organizations come from
[Supabase](https://supabase.com); everything else is static.

## Getting Started

Requires [Bun](https://bun.sh).

```bash
bun i
bun run dev     # http://localhost:4321
```

> [!NOTE]
> You need Supabase credentials (`SUPABASE_URL`, `SUPABASE_KEY`) in `.env`, because the resources
> section queries the database when the page renders. Contact me for credentials.

| Command                | What it does                                |
| ---------------------- | ------------------------------------------- |
| `bun run dev`          | Start the Astro dev server                  |
| `bun run build`        | Production build                            |
| `bun run preview`      | Serve the production build                  |
| `bun run lint`         | ESLint check                                |
| `bun run lint:fix`     | ESLint check (writes fixes)                 |
| `bun run test`         | Run tests once                              |
| `bun run test:watch`   | Run tests in watch mode                     |

## Stack

- [Astro 6](https://astro.build) with MDX content collections and React islands
- [React 19](https://react.dev) for interactive components
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS v4](https://tailwindcss.com), wired through `@tailwindcss/vite`, with the typography
  plugin for the guide's prose
- [shadcn/ui](https://ui.shadcn.com) on [Base UI](https://base-ui.com) for components
- [Supabase](https://supabase.com) for the database
- [Netlify](https://netlify.com) for hosting
- [Vitest](https://vitest.dev) (happy-dom + Testing Library) and [ESLint](https://eslint.org)

## How It Works

- `content/en.mdx` and `content/es.mdx` hold the guide itself, loaded as an Astro content collection
  and keyed by locale.
- `src/i18n/` holds the short UI strings for each locale. `es` must match the shape of `en`.
- `src/pages/index.astro` serves English; `src/pages/[locale]/index.astro` generates the other
  locales. Both render `src/components/main.astro`, which builds the nav from the guide's headings.
- `plugins/normalize.ts` is a remark plugin that strips diacritics from heading ids, so Spanish
  headings still get ASCII anchors.
- `src/components/resources.astro` loads the city list from Supabase; selecting a city calls
  `src/pages/api/resources.ts`, the only server-rendered route.
- `src/components/` contains the app components. `ui/` is generated by shadcn and ignored by lint.

## Build and Performance

- Static pages, with the Netlify adapter enabled only for production builds
- Critical CSS inlining (`@critters-rs/astro`) and unused CSS purging (`astro-purgecss`)
- Web manifest, 192/512 icons, Open Graph image, `robots.txt` and `sitemap.xml`
- Self-hosted Public Sans fonts, preloaded

## Testing

Tests live in `src/tests/` and run with `bun run test`. Astro components are rendered with the
Container API through the `renderAstro` helper in `src/tests/_utils.ts`, then queried with Testing
Library.
